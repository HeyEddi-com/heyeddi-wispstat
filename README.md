# HeyEddi Wispstat

Privacy-first, cookie-free web analytics running entirely on Cloudflare (Workers + D1 + KV). Open source (MIT), self-hosted, no tracking across sites, no selling data.

## Features

- **Cookie-free by default**: Daily visitor hashing with ephemeral salts
- **First-touch attribution**: Source, medium, campaign, referrer per visitor-day
- **Privacy-first**: No IPs stored, no cross-site tracking, optional DNT/GPC respect
- **Goals & conversions**: Event and path goals with per-source conversion rates
- **Event values**: Optional numeric value for revenue tracking
- **Self-hosted**: Runs on your own Cloudflare account
- **Free tier friendly**: ~50k pageviews/day on Cloudflare Free
- **Tiny tracker**: ≤2KB gzipped, no dependencies

## Quick Start

### Deploy to Cloudflare (Recommended)

1. Click the Deploy button:
   ```
   https://deploy.workers.cloudflare.com/?url=https://github.com/YOUR-ORG/heyeddi-wispstat
   ```

2. Cloudflare will:
   - Clone the repo
   - Create D1 databases, KV namespace
   - Run migrations
   - Deploy the Worker

3. Set secrets in the Cloudflare dashboard:
   - `SETUP_TOKEN`: A random token (≥32 characters) for first-run claim

4. Visit your Worker URL and claim the instance with your setup token

### Manual Setup

Requirements: Node.js 18+, a Cloudflare account

```bash
# Clone and install
git clone <repo-url>
cd heyeddi-wispstat
npm install

# Run setup script (interactive)
npm run setup

# The script will:
# - Create D1 databases (CORE, INGEST)
# - Create KV namespace (SALTS)
# - Run migrations
# - Generate and upload secrets
# - Deploy the Worker
# - Print your claim URL
```

### First-Run Claim

1. Visit your Worker URL (e.g., `https://wispstat.your-account.workers.dev`)
2. Enter the `SETUP_TOKEN` printed by the setup script
3. Create your owner email + password (≥12 chars)
4. Add your first site

### Add Analytics to Your Site

After adding a site, you'll get a snippet like:

```html
<script defer src="https://your-instance.workers.dev/ws.js" data-site="s_k7q2m9x4t8p3w6ab"></script>
```

The `data-site` is a randomly generated public site ID. Place it in your `<head>` or before `</body>`.

## Configuration

### Environment Variables (wrangler.toml)

- `DEFAULT_TZ`: Default timezone for new sites (default: `UTC`)
- `AUTH_PROVIDERS`: `local` (email+password) or `firebase` or both (default: `local`)
- `PUBLIC_BASE_URL`: Optional override for the instance URL

### Secrets (wrangler secret put or .dev.vars)

Required:
- `SETUP_TOKEN`: Token for first-run claim (≥32 chars)

Auto-generated by setup script:
- `SESSION_SECRET`: Session encryption key
- `TOKEN_KEY`: Visit token encryption (v1.2 feature)

Optional (for Firebase Auth):
- `FIREBASE_PROJECT_ID`
- `FIREBASE_WEB_CONFIG` (JSON string)

Optional (for features):
- `SLACK_WEBHOOK_URL`: Weekly digest
- `CF_API_TOKEN`, `CF_ACCOUNT_ID`: Nightly R2 backups

## Tracker API

```html
<!-- Attributes -->
<script defer 
  src="https://your-instance/ws.js"
  data-site="s_..."
  data-api="https://your-instance/e"
  data-spa="auto"
  data-hash-mode
  data-respect-dnt
  data-exclude="/admin,/preview"
  data-mask="/u/*,/invoice/*"
></script>
```

```js
// Queue stub (for early calls)
window.wispstat = window.wispstat || function() {
  (wispstat.q = wispstat.q || []).push(arguments);
};

// Track pageview (auto by default)
wispstat('pageview');

// Track custom event
wispstat('event', 'signup');

// Event with value (site currency)
wispstat('event', 'purchase', { value: 49.90 });
```

## Privacy Model

### What is stored

| Data | Handling |
|------|----------|
| IP address | Hashed in memory only; never stored |
| User-Agent | Parsed to coarse device/browser/OS; raw UA never stored |
| Visitor ID | `vh` = SHA-256(salt + site + IP + UA), first 16 bytes. Salt rotates daily and expires 6h after day ends |
| URL | Pathname only (no query/hash unless `data-hash-mode`) |
| Referrer | Hostname only |
| UTM params | Lowercased, length-limited, email-like values rejected |
| Language | Base language only (e.g., `en`, `es`, `pt`), never full list or region |
| Timestamps | Server time only |
| Custom events | Name + optional numeric value. **No properties in v1.0** |

### What is **never** collected

- Cookies, localStorage, sessionStorage, IndexedDB
- Canvas, fonts, screen size, viewport, timezone, hardware info
- Full language list, installed plugins, battery, connection type
- Client-side IDs, Firebase Analytics
- Third-party requests
- Raw IPs, User-Agents, emails, user IDs, query strings

### Legal Notes (not legal advice)

- Raw visitor data (pseudonymous) lives ~3 days, then dropped
- Aggregates kept indefinitely
- **Time Travel:** D1 history retains deleted rows for 7 days (Free) / 30 days (Paid)
- IP is processed transiently; Cloudflare sees it as network processor
- GDPR/ePrivacy applicability is not verified: get legal counsel for your jurisdiction
- See `templates/privacy-page.md` for a template notice

## Free Tier Limits

**Cloudflare Workers Free:**
- 100,000 requests/day (account-wide)
- 100,000 D1 rows written/day
- 5M D1 rows read/day

**Ceiling:** ~50k pageviews/day per instance at typical visitor-to-pageview ratios.

**Upgrade path:** Workers Paid removes daily caps (50M rows written/month included).

## Backups

1. **Time Travel** (built-in, always on): Restore to any minute within 7 days (Free) / 30 days (Paid)
   ```bash
   wrangler d1 time-travel restore wispstat-core --timestamp=<unix-seconds>
   ```

2. **R2 backups** (optional, nightly): Set `CF_API_TOKEN` and `CF_ACCOUNT_ID` secrets

3. **Manual export:**
   ```bash
   wrangler d1 export wispstat-core --remote --output=backup.sql
   ```
