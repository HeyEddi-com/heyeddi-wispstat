Open source · MIT

Install on your Worker

You run the stack. We don’t see your traffic. Clone the repo, claim the instance, paste one script tag.

  • 01
    Deploy the Worker Use the Cloudflare Deploy button in the README, or npm run setup then npm run deploy.
  • 02
    Claim with SETUP_TOKEN Open your *.workers.dev URL, enter the token from setup, create owner email + password.
  • 03
    Add a site + paste the snippet Overview → Add a site (one domain root). Put this before </body>: 
<script defer
  src="https://YOUR_WORKER/ws.js"
  data-site="s_…"></script>

Demo instance (HeyEddi): https://heyeddi-wispstat.heyeddi.workers.dev/ws.js — data-site is public; it is not a secret. Full guide: Docs → Install.

Why builders pick it

One script. Your Cloudflare account. No cookie banner theater.

  • Cookie-free by default Daily visitor hashing with rotating salts — no cross-site ID.
  • Forms stay private Submit events never include field values.
  • Free-tier friendly ~50k pageviews/day on Cloudflare Free is a realistic target.
  • Tiny + agent-ready ≈2KB tracker · MCP server for read-only agent access.
